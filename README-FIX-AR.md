# حزمة إصلاح PWA — حاسبة نقاط المسابقات (catloni.github.io/Kids) — نسخة بدون مجلدات

## أولًا: ما كانت المشكلة (من صورة PWABuilder)

| العنصر | النوع | المطلوب |
|---|---|---|
| 192×192 PNG | 🔴 خطأ يمنع التغليف | لا توجد أيقونة PNG؛ الملف كان SVG فقط |
| 512×512 PNG | 🟡 تحذير | مطلوبة للمتاجر |
| `id` في المانفست | 🟡 تحذير | تمييز ثابت للتطبيق |
| Screenshots | 🟡 تحذير | لقطات شاشة للعرض في المتاجر |

Service Worker سليم وفيه دعم دون اتصال؛ النواقص الزرقاء (Push / Background Sync) اختيارية لا تمنع التغليف.

## ثانيًا: بنية هذه النسخة (كل الملفات في جذر المستودع — لا مجلدات)

| الملف | الغرض | يستبدل / يضيف |
|---|---|---|
| `manifest.json` | المانفست الجديد (أيقونات + id + لقطة + اختصارات) | يستبدل الموجود |
| `index.html` | أُضيفت أيقونات Apple وأيقونة PNG | يستبدل الموجود |
| `sw.js` | كاش جديد v3 بالأيقونات المسطحة | يستبدل الموجود |
| `icon-192.png` | أيقونة 192×192 (تزيل الخطأ الأحمر) | جديد |
| `icon-512.png` | أيقونة 512×512 (تزيل تحذير 512) | جديد |
| `icon-maskable-512.png` | أيقونة Maskable | جديد |
| `apple-touch-icon-180.png` | أيقونة شاشة iPhone الرئيسية | جديد |
| `screenshot-home.png` | لقطة الشاشة للمانفست | جديد |
| `icon.svg` | الأيقونة الأصلية (تبقى كما هي) | موجود لديك |

## ثالثًا: الرفع من الجوال — ملفًا ملفًا (بدون مجلدات)

افتح المستودع: https://github.com/catloni/Kids

### أ) الملفات المصوّرة (PNG) — رفع واحدًا واحدًا
1. من صفحة المستودع اضغط **Add file → Upload files**.
2. ارفع الملف: `icon-192.png`
3. في مربع Commit اكتب رسالة مثل `add 192 icon` ثم اضغط **Commit changes**.
4. كرر الخطوات نفسها لكل ملف:
   - `icon-512.png`
   - `icon-maskable-512.png`
   - `apple-touch-icon-180.png`
   - `screenshot-home.png`

> إذا واجهت خيار السحب والإفلات فقط، اختر كل ملف على حدة من معرض الصور/الملفات بهاتفك. الأسماء في الجذر مباشرة (لا يوجد `icons/` ولا `screenshots/`).

### ب) الملفات النصية الثلاثة — الاستبدال بلصق المحتوى
الأسهل من رفعها:

1. افتح الملف `manifest.json` من صفحة المستودع → اضغط أيقونة القلم ✏️ → امسح المحتوى القديم والصق محتوى `manifest.json` الجديد كاملًا → Commit.
2. نفس الشيء لـ `sw.js`.
3. نفس الشيء لـ `index.html` (أو ارفعه من Upload files؛ لأن اسمه مطابق سيُستبدل تلقائيًا).

### بديل سريع للثلاثة نصوص
في صفحة المستودع: **Add file → Upload files**، واختر الملفات الثلاثة معًا دفعة واحدة (إن سمح التطبيق بذلك) ثم Commit واحد؛ رفع ملف بنفس الاسم يستبدله تلقائيًا.

## رابعًا: إعادة الفحص في PWABuilder
1. انتظر 1–3 دقائق بعد آخر Commit حتى ينشر GitHub Pages.
2. افتح https://www.pwabuilder.com/ وأدخل: `https://catloni.github.io/Kids/` وابدأ الفحص.
3. يختفي العدّاد الأحمر وتصبح أيقونة **Package For Stores** جاهزة.

## ملاحظات
- لا تنشئ مجلدات؛ كل الملفات في نفس مستوى `index.html`.
- لقطة الشاشة الحالية للحالة الفارغة؛ إن التقطت لقطة بعد إضافة لاعبين، استبدل اسم `screenshot-home.png` بنفس الاسم (أحدّث `src` داخل `manifest.json` إن غيّرت الاسم).
